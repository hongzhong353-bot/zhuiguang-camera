关于追光相机

一款为摄影爱好者做的网页相机：预录制帮你留住按下快门前的瞬间，厂商风格模拟让照片换上各家相机的色彩味道，光线与计算工具帮你算好每一次出片。

🔒 隐私：所有处理均在本地完成，照片、视频与位置不会上传到任何服务器。

v4.9 新增

  • 相册批量删除：长按一张进入选定，再点其他张多选，一次全删；另有“全部删除”，删前都按条数确认
  • 取景界面仿 vivo 重排：顶栏只留语音与更多两个图标，防抖 / 帧率 / 预录时长 / 照片比例移进更多面板的拍摄设置区
  • 变焦改紧凑药丸：约 250px 居中圆角条，紧贴模式栏上方，刻度与拖动不变
  • 风格开关移到右侧边缘（美颜按钮下方）；风格条按 vivo 色彩风格选择器打磨：横向滑动带吸附、点卡片切换、选中金色高亮
  • 照片比例：4:3 / 16:9 / 1:1 三档，默认 4:3；拍照按比例裁切，取景器显示取景框（框内即拍到的范围）
  • 震动反馈：选风格、选照片、切模式、点设置药丸时轻震一下（约 12 毫秒）
  • 修复：视频缩略图黑块——取帧时往后探 0.1 秒，实在取不到的显示 🎬 占位，不再纯黑

v4.8 新增

  • 全屏相册：点左下角缩略图打开，网格浏览，点一张全屏看，左右滑切换，可下载/删除；缩略图显示作品库最新一张，重启 App 也还在
  • 语音控制诊断：识别到的字实时显示（“听到：…”），命令匹配/没匹配上/联网失败都有提示；10 秒没结果会提醒检查网络；加“开始预录 / 预录”口令
  • 变焦滑条圆点改小（约 23px），轨道变细
  • 修复：风格开关压住变焦刻度（移到拨盘上方）；缓存进度压住语音提示（语音提示移到缓存行下方）

v4.7 新增

  • 磨皮再加强：模糊半径加大 + 双重模糊 + 混合上限提高，默认 30 就一眼可见
  • 修复：佳能人像实时预览偏红（实时滤镜去掉全帧 sepia 与 hue-rotate）
  • 删除：拍完可在回顾面板直接删除；作品库删除前会确认
  • 变焦拨盘改扁平横滑条：更矮、更靠下，不再遮挡取景；只响应轨道上的拖动，点美颜不再误触变焦
  • 风格条可收起：默认收起只留风格开关，点一下展开、再点收起
  • 预录缓存改为“已缓存 N 秒 / M 秒”实时进度
  • 顶部控制行上移，提示气泡不再遮挡变焦读数
  • 语音控制：麦克风权限被拒时明确提示；“开始录像”加识别变体，预录模式下会说明含预录片段

v4 新增

  • 厂商风格色彩重调：按色相分段调色，佳能人像红里透白、富士 Velvia 与 Classic Chrome 各有招牌味道
  • 美颜：锐化 / 磨皮 / 提亮三滑杆，肤色往佳能人像方向调（磨皮仅作用于照片）
  • 降噪：前后帧混合 + 轻微模糊，静止画面效果最好
  • 悬浮美颜按钮：取景器右侧一点即开美颜面板
  • 去瑕疵：拍照后点按痣 / 痘痘修复，带撤销与恢复原图
  • 实际分辨率显示：美颜面板内可见摄像头真实分辨率
  • 修复：拍照 / 录像模式下不再显示预录 chip
  • 修复：磨皮模糊半径随分辨率放大（1080p 约 8px），此前半径 2px 在高清照片上几乎看不出效果

v3.x 改进

  • 帧率选择：24 / 30 / 60fps，设备给不到时如实显示实际帧率
  • 变焦拨盘：滚轮式焦段选择，跟手变焦（拖动即时预览、松手光学接手）
  • 超级防抖：陀螺仪电子防抖，左上角开关
  • 全屏与 PWA：可全屏拍摄，可添加到主屏幕
  • 桌面端适配：双栏布局与键盘快捷键
  • 模式合并：人像 / 风光归入风格，模式只剩预录 / 拍照 / 录像

v3 新增

  • 拍摄时实时风格模拟：取景器风格条，拍照与录像都带上所选风格
  • 本地作品库：照片与视频自动存到本机浏览器，可随时下载或删除
  • 全国省市县三级选择：光线页可精确到县（县为可选项）
  • 测距辅助：对焦距离直读 + 参照物估算（需标定）
  • 修复：缓存秒数按时间戳计算，不再数数据块

v2 新增

  • 原生相机式全屏取景：焦段选择、模式栏、快门行
  • 拍照模式：实时画面快照保存为 JPG
  • 语音控制：说“开始录像 / 停止录像 / 拍照”即可操作（需联网识别）
  • 降噪：录制音频开启浏览器内置降噪、回声消除

  • 直方图与照片取色配色
  • AI 摄影助手：按场景推荐拍摄参数
